## 3. Minimum Standard Per Lesson

Every lesson (all levels A1-C1) should meet this minimum:

| Component | Required? | Notes |
|-----------|-----------|-------|
| **Detailed explanation** | REQUIRED | 300-800 chars depending on complexity. Context, use cases, register notes. |
| **Examples** | REQUIRED | 3-5 example sentences minimum |
| **Common mistakes** | REQUIRED | 2-3 common learner errors with corrections |
| **Forms table** | REQUIRED (if grammar) | Declension, conjugation, or structure table |
| **Mini-drills** | REQUIRED | 5-10 short practice items per lesson |
| **Linked exercises** | REQUIRED | Every lesson must connect to specific questions/exercises |
| **Vocabulary section** | REQUIRED | List of key words from the lesson |
| **Pronunciation notes** | REQUIRED | At minimum for words with non-obvious pronunciation |
| **Medical/Germany-life examples** | RECOMMENDED | Where relevant, use medical or German administrative context |
| **Guided practice** | REQUIRED | Step-by-step practice with hints |
| **Independent practice** | RECOMMENDED | Unguided application of concepts |
| **Review summary** | REQUIRED | Brief recap at end |
