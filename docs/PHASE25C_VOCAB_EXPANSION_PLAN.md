## Source Policy

All entries are original. Sources:
- No copyrighted lists. No web scraping of dictionary sites.
- Vocabulary comes from common German textbooks curriculum (B2/C1 scope)
- Medical vocabulary from real clinical context
- No direct copying from Langenscheidt, Duden, PONS, or other copyrighted dictionaries

## Schema Requirements

### For all new entries

```json
{
  "id": "unique_id",
  "level": "B2|C1|FSP",
  "word": "German word or phrase",
  "translation": "English meaning",
  "example": "German example sentence",
  "exampleTranslation": "English translation of example",
  "tags": ["array", "of", "context", "tags"],
  "lessonId": "lesson reference",
  "taughtInLessonId": "lesson reference",
  "partOfSpeech": "noun|verb|adjective|adverb|phrase|expression",
  "topic": "topic name",
  "source": "original",
  "license": "custom/original"
}
```

### For Nouns (additional)

```json
{
  "article": "der|die|das",
  "plural": "die Pluralform",
  "countability": "countable|uncountable",
  "pluralStatus": "known|not-applicable"
}
```

### For FSP entries (additional)

```json
{
  "category": "General Hospital|Anamnesis|...",
  "layExplanation": "Patient-friendly explanation",
  "patientFriendlyPhrase": "Patient-friendly usage phrase",
  "doctorToDoctorPhrase": "Professional expression"
}
```

### For phrase/expression entries

```json
{
  "partOfSpeech": "phrase",
  "article": null
  // No article or plural fields
}
```

## Duplicate Prevention

The import script will:
1. Normalize words (lowercase, strip surrounding whitespace)
2. Check across all levels + FSP for exact word matches
3. Check for near-duplicates (same word, different level)
4. Reject any entry whose normalized word already exists
5. Log all rejected duplicates

## Flashcard Compatibility

- Nouns: article, plural, countability, pluralStatus fields ensure correct card generation
- Phrases/expressions: no article/plural cards generated (POS check)
- All entries: meaning cards always valid
- Unknown plurals: not generated for phrase entries

## ID Convention

- B2: `B2_vocab_XXXX` (starting after max existing)
- C1: `C1_vocab_XXXX` (starting after max existing)
- FSP: `fsp_v_XXXX` (starting after max existing)
