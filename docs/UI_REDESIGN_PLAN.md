# UI Redesign Plan

## Current UI Problems

- Some sections feel dense because dashboard, progress, account, and practice cards compete for attention.
- Remediation actions need clearer before/after expectations.
- Account sync looked like a missing feature instead of an intentional local-first mode.
- Mobile layout needs tighter hierarchy and fewer equal-weight panels.

## Dashboard Simplification

- Primary card: Today's Plan.
- Secondary card: Progress toward goal.
- Tertiary cards: Weak areas, Continue, Exam readiness.
- Keep current level and estimated finish visible without making every metric equally prominent.

## Navigation Structure

- Keep compact level selector.
- Keep Dashboard prominent.
- Group Practice, Review, FSP, Resources, Settings/Goal.
- On mobile, collapse secondary links into a menu while preserving the level selector.

## Visual System

- Buttons: consistent height, icon + clear command label.
- Cards: use 8px radius or existing app radius, avoid cards inside cards.
- Typography: smaller headings inside panels, clear labels for metrics.
- Spacing: use predictable vertical rhythm between cards.
- Progress cards: show target, current, remaining, and next action.

## Priority Areas

- Daily plan cards: show task, estimated minutes, and why it matters.
- Mistake/remediation UI: show weakness, source, action, expected result, and progress.
- Account UI: local/account tabs, clean disabled state, clear sync promise.
- FSP section: separate patient-history, presentation, Arztbrief, and exam simulation flows.

## Staged Redesign Plan

1. Polish account/local mode card.
2. Clarify remediation cards and targeted sessions.
3. Improve study goal card with 120-minute option.
4. Simplify dashboard hierarchy.
5. Standardize daily plan cards.
6. Improve mobile navigation and dashboard stacking.
7. Redesign FSP hub after the curriculum model is stable.
