# A1 Target Curriculum

## Purpose
Define the complete A1 German curriculum for deutsch-klinik. Everything a beginner needs to reach A1 level and pass Goethe A1 certification, with medical context where natural.

## Grammar Topics (Goethe A1 Coverage)

### Core Grammar (must be explicitly taught)

| # | Topic | Notes | Priority |
|---|-------|-------|----------|
| 1 | Definite articles (der, die, das) | Nominative | P0 |
| 2 | Indefinite articles (ein, eine) | Nominative | P0 |
| 3 | Negative articles (kein, keine) | Nominative + accusative | P0 |
| 4 | Personal pronouns (ich, du, er/sie/es, wir, ihr, sie/Sie) | Nominative | P0 |
| 5 | Present tense: sein | Full conjugation | P0 |
| 6 | Present tense: haben | Full conjugation | P0 |
| 7 | Present tense: regular verbs (wohnen, kommen, heißen, etc.) | Full conjugation | P0 |
| 8 | Present tense: irregular verbs (sprechen, essen, geben, etc.) | Vowel changes | P0 |
| 9 | Modal verbs: können, müssen, wollen, möchten | Present tense | P0 |
| 10 | W-questions (wer, was, wo, wie, woher, wann, warum) | Question words | P0 |
| 11 | Yes/no questions | Verb-first order | P0 |
| 12 | Negation: nicht (position rules) | End of clause vs before specific word | P0 |
| 13 | Negation: kein/keine | Article negation | P0 |
| 14 | Accusative case | Articles, pronouns (mich/dich), "einen/eine/keinen" | P0 |
| 15 | Sentence order: main clause (SVO, verb second) | Position rules | P0 |
| 16 | Numbers 0-100 | Cardinal | P0 |
| 17 | Ordinal numbers (erste, zweite, etc.) | For dates | P0 |
| 18 | Possessive articles (mein/dein/sein/ihr/unser/euer/Ihr) | Nominative | P0 |
| 19 | Plural forms | -e, -er, -(e)n, -s, umlaut patterns | P0 |
| 20 | Separable verbs (anfangen, aufstehen, einkaufen, etc.) | Prefix position | P0 |
| 21 | Imperatives (du/Sie forms) | Polite and familiar | P0 |
| 22 | Prepositions: im, am, um (time) | For time expressions | P0 |
| 23 | Prepositions: in, auf, bei, mit, von, zu (place/people) | Basic usage only | P0 |
| 24 | Colors as adjectives | Basic attributive use | P1 |
| 25 | Weather expressions with "es" | es regnet, es ist kalt | P1 |

### Grammar Topics A2+ (NOT to be tested at A1)
- Dative case (except as fixed phrases: mir geht's gut, zum, beim)
- Past tense (Präteritum/Perfekt)
- Comparative/superlative
- Subordinate clauses (weil, dass, wenn)
- Relative clauses
- Passive voice
- Konjunktiv II (würde, hätte)
